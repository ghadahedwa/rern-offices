# استيضاحات موديول «أجندة الاجتماعات» — للعميل

> نقاط محتاجة تأكيد قبل بناء الجدول والشاشة.

## ١. حقول الاجتماع
مقترح ٧ حقول: **التاريخ، الساعة، الموضوع، المكان، الأعضاء/المعنيون، القرار، ملاحظات**.
- هل نبقّي **الساعة** و**الملاحظات**؟ (كانوا في الطلب الأصلي)

## ٢. تسمية الحقول
- «الأعضاء» ولا «المعني بالاجتماع»؟
- «القرار» ولا «نتيجة الاجتماع»؟

## ٣. الأعضاء / المعنيون (الأهم)
- يتكتبوا **نص حر** (سطر واحد)، ولا **نضيفهم واحد واحد كقائمة** (يتعدّوا، وتقارير لاحقاً «اجتماعات فلان»)؟
- ومعاهم **صفة** (رئيس / عضو / أمين سر)، ولا **اسم بس**؟

## ٤. المكان
- **نص حر** يُكتب في كل اجتماع، ولا **اختيار من قائمة أماكن** معرّفة مسبقاً؟

## ٥. الصلاحيات
- تأكيد الأدوار: **عرض / إضافة / تعديل / حذف** الأجندة.

## ٦. البحث
- تأكيد معايير البحث: **بالكلمة / بالتاريخ / بالموضوع** — فيه معيار إضافي مطلوب؟
