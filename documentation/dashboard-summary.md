# لوحة التحكم — ملخص تنفيذي
### نظام مقرات الشهر العقاري والتوثيق

---

## نظرة عامة
لوحة تحكم تفاعلية تعرض بيانات النظام في الوقت الفعلي، مصممة بأسلوب احترافي تدعم الوضع الليلي والنهاري وتعمل بشكل كامل على جميع أحجام الشاشات.

---

## بطاقات الأرقام السريعة (KPI)
- إجمالي المقرات
- عدد المحافظات
- عدد المستخدمين
- مقرات جديدة هذا الشهر

---

## التحذيرات التلقائية
تنبيه فوري بعدد المقرات التي لم تُزر منذ أكثر من 6 أشهر، مع زر مباشر يفتح قائمة تلك المقرات بفلتر جاهز.

---

## التوزيع البياني (3 مخططات)
- **توزيع المقرات على المحافظات** — مخطط عمودي كامل العرض، يعرض كل المحافظات، وعند المرور بالمؤشر يظهر ملخص إحصائيات كل محافظة (توثيق / قانون ٩ / قانون ٢٧ / سجل لآخر سنتين)
- **توزيع حسب النوع** — مخطط دائري
- **توزيع حسب الحالة الإنشائية** — مخطط أفقي بألوان تعبيرية من الأخضر (ممتازة) إلى الأحمر (متهالكة)

---

## ملخص الإحصائيات السنوية
ست بطاقات منفردة لكل نوع، بترتيب صفحة الإحصائيات:

| النوع | البيانات المعروضة |
|---|---|
| معاملات التوثيق | السنة الحالية + السابقة + نسبة التغيير |
| طلبات الشهر | السنة الحالية + السابقة + نسبة التغيير |
| مشهرات قانون ٩ | السنة الحالية + السابقة + نسبة التغيير |
| مشهرات قانون ٢٧ | السنة الحالية + السابقة + نسبة التغيير |
| طلبات السجل العيني | السنة الحالية + السابقة + نسبة التغيير |
| النماذج والحوافظ | بيع النماذج وبيع الحوافظ — كلٌ على حدة (من سنة 2026) |

كل بطاقة تعرض مؤشر ↑ ارتفاع أو ↓ انخفاض مقارنةً بالسنة السابقة.

---

## سجل النشاط
- تسجيل تلقائي لجميع العمليات: إضافة / تعديل / حذف / **عرض** مقر، وتسجيل الدخول والخروج
- **يتحدث تلقائياً كل 5 دقائق** دون إعادة تحميل الصفحة
- بحث وفلتر فوري حسب نوع العملية (إضافة / تعديل / حذف / عرض / دخول / خروج)
- رابط مباشر لكل مقر من داخل السجل (يفتح صفحة العرض أو التعديل حسب صلاحية المستخدم)
- **أداة حذف السجلات القديمة** (super-admin فقط): حذف الأقدم من 3 أيام / أسبوع / أسبوعين / 3 أسابيع / شهر

---

## المستخدمون المتصلون الآن
عرض فوري لمن هو متصل بالنظام حالياً مع عنوان الـ IP، بنطاق يختلف حسب مستوى المستخدم (انظر أدناه).

---

## نظام المستويات الهرمي (الرؤية)

لكل دور **مستوى** يحدد نشاط مَن يراه صاحبه. الصلاحيات (ماذا يفعل) منفصلة تماماً عن المستوى (مَن يرى نشاطه).

| المستوى | الدور | يرى نشاط |
|---|---|---|
| 1 | مفتش | نشاطه فقط |
| 2 | مستشار | المفتشين والمستشارين في محافظاته |
| 3 | رئيس | المستشارين والمفتشين والرؤساء في محافظاته |

**القواعد:**
- الأدنى لا يرى الأعلى • الأقران (نفس المستوى) يرون بعضهم
- نشاط المقرات يُفلتر حسب **محافظة المقر** (المشرف يرى نشاط مفتشه في المحافظات المشتركة فقط)
- الدخول/الخروج يُفلتر حسب مشاركة المحافظة
- super-admin فوق الجميع دائماً (لا يراه أي مشرف)

| الميزة | super-admin | مشرف (مستشار/رئيس) | مفتش |

| تنبيه المقرات غير المزارة | كل مصر | محافظاته | محافظاته |
