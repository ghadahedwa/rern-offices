## المرحلة الأولى — قائمة مقرات مفلترة
**الصفحة:** `reports/multi-office`
**الحالة:** ✅ الواجهة والفلاتر منجزة — **التصدير لم يبدأ** (قيد الاتفاق)

### نمط التشغيل — زرار "بحث" (مهم)
الصفحة **لا تحمّل النتائج لحظياً**. المستخدم يحدّد كل المحددات ثم يضغط **بحث** → استعلام واحد.
- الفلاتر تحدّث حالتها بدون استعلام (`$wire.set(..., false)` للـ multi-selects، و`wire:model` المؤجّل للباقي)
- **استثناء:** المحافظة `live` فقط — عشان قائمة المقرات تتحدث حسب المحافظة المختارة
- `search()` يأخذ snapshot من المحددات في `$applied`، والاستعلام يقرأ من `$applied` فقط
- النتائج لا تظهر إلا بعد أول بحث (قبلها رسالة إرشاد)
- زرار **مسح** (في الهيدر) يصفّر كل شيء

### مكوّن الـ multi-select (partial مشترك)
`resources/views/livewire/reports/includes/checkbox-group.blade.php`
- dropdown منبثق قابل للبحث (لا يأخذ مساحة الصفحة)
- بحث داخلي + **اختر الكل** (يحترم البحث) ⟷ **مسح التحديد** في صف واحد أعلى القائمة
- الزر يعرض **أسماء** الاختيارات (مع tooltip)، مش العدد
- `z-50` عند الفتح (يغطي الحقول خلفه)
- معامل `live` (true للمحافظة فقط)

### النتيجة
جدول: اسم المقر / المحافظة / النوع / نوع الاتصال / الحالة الإنشائية / آخر زيارة + عدّاد النتائج

### التصدير — 🔄 قيد التنفيذ
**الصيغتان معاً: Excel + PDF. أعمدة/حقول ثابتة (لا تتبع الفلاتر).**
يصدّر **نتائج البحث المطبّقة** (`$applied`) — متاح بعد الضغط على "بحث".

#### Excel — جدول عريض شامل (~40 عمود) برؤوس مجمّعة
- صف رؤوس علوي بعناوين الأقسام (خلايا مدمجة ملوّنة) + صف رؤوس الأعمدة
- تجميد أول عمود (الاسم) + صف الرؤوس · Auto-filter · تظليل متناوب · تلوين شرطي للتقييمات
- حزمة: `maatwebsite/excel`

#### PDF — بلوك لكل مقر (تخطيط مقارنة مدمج، mPDF)
**عمود الهوية لكل مقر:** اسم المقر · (العنوان بين قوسين) · آخر زيارة · `المحافظة — المستشار المشرف`

**الأقسام داخل بلوك كل مقر:**
| # | القسم | الصفوف / التخطيط |
|---|-------|------------------|
| 1 | البيانات الأساسية | النوع والموقع · تاريخ الإنشاء · المحكمة · المساحة والطوابق · الوضع التعاقدي والحالة الإنشائية · رابط الخريطة (لينك) |
| 2 | أوقات وأنظمة العمل | نظام · ساعات · أيام · اتصال · ميكنة · شبابيك (شرطي) |
| 3 | الخدمات والتجهيزات | ميكروفيلم · ذوي الهمم · حماية مدنية · تصوير · بوفيه · عقد نظافة |
| 4 | الأنظمة التقنية | برايل · طوابير · كاميرات |
| 5 | عدد الأجهزة | عمودين: كمبيوتر/شاشات · طابعات/ماسحات · بصمة/دفع · مكيفات/UPS |
| 6 | العدادات | عمودين: كهرباء نوع/مديونية · مياه نوع/مديونية |
| 7 | التقييم والجودة | عمودين: نظافة/أرشيف · التزام/معاملة |
| 8 | الأجهزة المعطلة | قائمة `نوع: عدد` أو "لا يوجد" |
| 9 | ملاحظات المقر | كامل العرض (اختياري): احتياجات · سلبيات وحلول · مقترحات |

**🔖 مؤجّل (نرجعله بعد اعتماد الشكل):**
- الصور وملفات المستندات (سند ملكية/حيازة · قرار إنشاء) — النظام لا يصنّف المستندات حالياً (كلها `document` عام)؛ القرار: مؤشرات/أعداد أم تصنيف فعلي (migration)
- ملخص الإحصائيات (سلاسل زمنية)

**🗑️ متجاهَل:** `debt_amount` (غير مستخدم) · `parent_office_id` (مخفي) · `avg_daily_transactions` (في صفحة الإحصائيات)

### ملاحظات التنفيذ
- نفس نظام الصلاحيات: `mount()` يتطلب super-admin أو `offices.export`؛ المستخدم العادي يرى محافظاته فقط (في الفلتر والنتائج)
- الـ component: `App\Livewire\Reports\MultiOffice`
- كل النصوص العربية في `lang/ar/home.php` (مفاتيح `report_*`)
